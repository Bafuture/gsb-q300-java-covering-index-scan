## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的查询只需要索引里已有的列，但仍然回表取数据，白白多了一次读取。请从零实现一个覆盖索引扫描组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持定义索引包含的列集合，并标记索引键列与附加包含列；2) 支持判断查询所需的列是否被索引完全覆盖，覆盖时不得回表，需给出回表次数对比；3) 支持覆盖扫描执行：直接从索引产出结果，并保持按索引键有序；4) 支持部分覆盖：所需列部分在索引中时，先由索引过滤再回表取缺失列，需说明取舍；5) 支持索引列更新：被更新列的索引值要同步维护，不得让覆盖扫描读到旧值，需有测试证明；6) 正确性：覆盖扫描结果与回表查询结果完全一致，需用随机数据验证；7) 提供统计：索引扫描行数、回表行数、被覆盖的列数与扫描耗时；8) 测试覆盖完全覆盖不回表、部分覆盖回表、有序输出、列更新一致性、正确性验证与统计；`mvn -q verify` 一条命令跑通。
